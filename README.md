## Project Overview

Analysed Tinder user data to understand user engagement, matching patterns, communication behaviour and demographic trends. Developed interactive visualisations using Tableau to identify patterns in user activity and engagement across different demographics and geographical locations.

## Objectives

- Understand user engagement through app opens, swipe likes and matches.
- Analyse match rates and conversation patterns across genders.
- Examine the relationship between user activity and matching behaviour.
- Explore geographical differences in user engagement.
- Identify demographic patterns across different age groups.

## Key Areas of Analysis

1. **User Engagement:** Analysed app opens, swipe likes, matches and conversations using a conversion funnel.
2. **Gender-Based Analysis:** Compared match rates and user activity across male and female users.
3. **Conversation Behaviour:** Examined conversation duration, ghosting patterns and sensitivity ratios.
4. **Geographical Analysis:** Visualised swipe likes across countries to understand location-based engagement.
5. **Demographic Analysis:** Explored user behaviour across different age groups and genders.

## Tools & Techniques

- **Tableau:** Dashboard creation, data visualisation, geographical mapping and interactive charts.
- **Microsoft Excel:** Data handling and preparation.
- **Exploratory Data Analysis (EDA):** Identifying patterns, trends and relationships within user data.

## Key Takeaways

- Visualised the conversion funnel from swipe likes to matches and conversations.
- Identified differences in matching behaviour across genders.
- Observed variations in user engagement across age groups and geographical locations.
- Explored conversation patterns and ghosting behaviour to understand user interactions.
